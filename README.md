# Khanya Ngema - Player Profile

A responsive football player profile and photo gallery for Khanya Ngema. The site is built as a static HTML page and includes player information, career history, stats, coach references, gallery photos, and a link to YouTube highlights.

## Files

- `index.html` - the profile page and its styling
- `ID.jpg` - profile portrait
- `BW.JPEG`, `TUKS.PNG`, `EHS.JPEG`, `KZN.jpeg`, `GR.JPEG` - gallery images
- `YT.jpg` - YouTube highlights icon

Keep the image files in the same folder as `index.html`; the page references them by their filenames.

## Preview locally

Open `index.html` in a web browser.

## Deploy with GitHub Pages

1. Open the repository's **Settings** tab.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder, then save.
5. After GitHub Pages finishes building, use the URL shown in the Pages settings.

To publish changes, commit and push them to the `main` branch.
